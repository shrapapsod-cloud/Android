# iOS Home — рабочий стол в стиле iOS 14

Лаунчер для Android 12+ (Kotlin + Jetpack Compose), без лишних библиотек.

## Новое в v3
- Настройки — отдельное полноэкранное приложение (системный жест «назад» работает): обои, размер значков 80–140 %, подписи, наборы значков, размытие, рабочий стол по умолчанию / вернуть MIUI, счётчики, сброс раскладки.
- Наборы значков из Play Маркета (формат Nova/ADW/Apex).
- Пока тащишь значок или виджет, остальные сразу расступаются и возвращаются обратно (и в доке тоже).
- Заметка: заголовок + текст; тап мимо — убрать клавиатуру, ещё тап — закрыть.
- Контекстное меню у значка (быстрые действия приложения, Поделиться, О приложении), меню у виджета.
- Страница «Сегодня» слева, папки в Библиотеке приложений, недавние в поиске, вибрация, анимация возврата домой.
- Круглые элементы (счётчики, «−», переключатели, точки) — настоящие круги.

## Новое в v2
- Свой фон: любое фото из галереи (Настройки → «Выбрать фото для фона»).
- Размытие («стекло» iOS) у дока, меню, библиотеки, поиска, кнопок; фон размывается под меню и поиском.
- Свайпы как в iOS: вниз из середины — поиск (Spotlight), вниз от верхнего края — шторка,
  пружинное листание страниц, долгое нажатие по пустому месту — режим правки.
- Можно скрыть подписи под иконками.
- Сетка iOS 14: поля 24dp, иконка 60dp, виджет 2×2 — ровно две колонки иконок.
- Все углы — плавные (continuous corners), включая счётчики, кнопки и точки.
- Настройки: зажать иконку → «Настройки рабочего стола», или режим правки → «Настройки».
  Там же «Вернуть рабочий стол MIUI».

## Что есть
- Сетка 4×6, док на 4 приложения, точки страниц, обои — системные.
- Иконки ВСЕХ приложений с плавными углами iOS (continuous corners / squircle, радиус 22.37%).
- Виджеты 2×2: Часы (аналоговые, с секундной стрелкой), Календарь, Заметки (редактируются), Аккумулятор.
- Первая страница сразу раскладывается как на iPhone: виджеты слева, приложения справа.
- Красные счётчики непрочитанного на иконках (нужен «Доступ к уведомлениям» — баннер подскажет).
- Долгое нажатие: меню (Изменить экран «Домой», Удалить с экрана, О приложении, Удалить приложение).
- Режим правки: иконки покачиваются, «−» в углу, перетаскивание, перенос между страницами (держать у края),
  в док и из дока, кнопка «+» добавляет виджет, «Готово».
- Последняя страница — Библиотека приложений с поиском.
- Свайп вниз — шторка уведомлений. Кнопка «Домой» — на первую страницу.
- Запуск приложения с анимацией «вырастания» из иконки.

## Как получить APK без компьютера (GitHub)
1. Зарегистрируйся на github.com, нажми «+» → New repository → любое имя → Create.
2. На странице репозитория: «uploading an existing file» → перетащи ВСЁ содержимое распакованного архива
   (папки app, .github, файлы build.gradle.kts и т.д.) → Commit changes.
   Папка .github скрытая: если не загружается — создай файл вручную: Add file → Create new file →
   имя `.github/workflows/build-apk.yml` → вставь содержимое из архива.
3. Вкладка Actions → Build APK → дождись зелёной галочки (5–8 минут).
4. Открой сборку → внизу Artifacts → скачай zip → внутри APK → установи.
5. Нажми кнопку «Домой» → выбери iOS Home → «Всегда»
   (или в самом приложении нажми баннер «сделать рабочим столом по умолчанию»).

На MIUI: Настройки → Приложения → Приложения по умолчанию → Рабочий стол → iOS Home.
Вернуть MIUI — там же выбрать «Рабочий стол системы».
